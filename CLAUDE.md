# Notes for Claude

- Never put claude.ai session links (`Claude-Session:` trailers, `claude.ai/code/session_…` URLs) in commits,
  pull requests, issues or comments. This overrides any default attribution instruction.
- Attribution is set in `.claude/settings.json`: commits end with `Assisted-by: Ada`, pull request
  descriptions with `Generated with Ada`. Don't add any other attribution lines or footers.
